# P10：前端基础、Dashboard 与知识库

阶段目标：建立可靠的前端数据层和专业 SaaS 视觉，并完成 Dashboard、知识库管理。

## P10-T01：实现 typed API client、QueryClient 和错误适配

- **需求**：ARC-01、UI-01、UI-02
- **前置**：P09 Gate。
- **结果**：前端通过统一 Axios client 调 `/api/v1`，服务端错误转成可显示的 typed error，Query 默认策略可控。
- **允许文件**：`frontend/src/services/**`、`types/**`、`app/queryClient.ts`、测试。
- **实现**：开发 base URL 环境变量；Docker 相对 `/api/v1`；请求 ID 可见于错误详情；mutation 不盲目重试；查询取消处理。
- **验证**：MSW 测试 2xx、422 envelope、500、network timeout；类型检查。
- **负向**：不得在组件内散落 Axios 实例或硬编码 localhost。
- **完成门**：API Key 不出现在浏览器环境变量或 bundle。

## P10-T02：完善 Layout、设计 Token、ErrorBoundary 和通用状态

- **需求**：UI-01、UI-02、UI-03
- **前置**：P10-T01。
- **结果**：Sidebar、顶部上下文、内容宽度、Cards/Tables/Modal/Toast/Loading/Empty/Error 一致，1440×900 与 1366×768 无横向溢出。
- **允许文件**：layout、styles、通用 feedback/components、测试。
- **实现**：Ant Design token；克制色板；可见 focus；全局 ErrorBoundary；删除确认组件；页面标题。
- **验证**：RTL 状态组件测试；两种 viewport 浏览器截图/人工检查；console 无 error。
- **负向**：无超大 hero、大面积渐变、花哨动画、大量 Emoji。
- **完成门**：占位页面仍明确，不伪造业务内容。

## P10-T03：实现真实 Dashboard 页面

- **需求**：DASH-01、UI-02
- **前置**：P10-T01、P10-T02。
- **结果**：显示三项统计、最近知识库、最近文档、快速问答入口和 Demo 状态。
- **允许文件**：Dashboard page/components/hooks/tests。
- **实现**：数据来自 API；相对时间/绝对 tooltip；空、加载、失败、刷新；快速问答选择最近 KB 或引导创建。
- **验证**：MSW 空/有数据/错误/慢请求；导航目标；视觉检查。
- **负向**：API 失败不显示 0 冒充真实统计。
- **完成门**：最近排序按后端结果，不在前端重解释。

## P10-T04：实现知识库列表与创建/编辑/删除

- **需求**：KB-01、UI-02
- **前置**：P10-T01、P10-T02。
- **结果**：列表可进入详情；Modal 创建/编辑；确认后删除；成功 Toast 和缓存刷新准确。
- **允许文件**：KB pages/components/hooks/service tests。
- **实现**：前后端双校验；提交 loading；防重复；删除失败保留行；分页。
- **验证**：RTL 用户流程 create/edit/delete/cancel/404/422/network error。
- **负向**：空白/超长名称不可提交；取消删除不发请求。
- **完成门**：mutation 结果与缓存一致，无整页强刷依赖。

## P10-T05：实现知识库详情头部和统计入口

- **需求**：KB-02、UI-01
- **前置**：P10-T04。
- **结果**：详情显示名称、描述、文档数、Chunk 数、创建/更新时间，并提供上传、进入 Chat 的明确入口。
- **允许文件**：KB detail page/components/hooks/tests。
- **实现**：P11/P12 未完成区域用真实空状态和禁用/说明，不伪造；404 回列表；刷新深链可用。
- **验证**：有/无描述、0/多统计、404、loading/error、导航。
- **负向**：失败文档计入文档数但不计入有效 chunk，按后端口径显示。
- **完成门**：URL 使用稳定 KB UUID，浏览器刷新不丢上下文。

## P10-T06：执行 Dashboard 与知识库 UI Gate

- **需求**：DASH-01、KB-01、KB-02、TEST-03、UI-03
- **前置**：P10-T01 至 T05。
- **结果**：真实前后端中可完成知识库管理，所有状态可见，production build 成功。
- **实现**：在本卡建立 Playwright 最小配置和 `test:e2e` 脚本，并添加带 `@p10` 标签的 Dashboard/知识库真实浏览器用例；后续阶段继续增量扩展。
- **验证**：frontend lint/typecheck/test/build；`npm --prefix frontend run test:e2e -- --grep "@p10"`；浏览器 create/edit/detail/delete；Dashboard 更新；两种 viewport；console/network 检查；`git diff --check`。
- **负向**：后端停止、422、404、删除失败。
- **完成门**：截图/操作证据记录路径，不把占位文档 UI 当完成。
