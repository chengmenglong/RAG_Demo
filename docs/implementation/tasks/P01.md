# P01：可运行骨架

阶段目标：建立最小但真实可运行的前后端。不得提前实现数据库或业务功能。

## P01-T01：建立根目录工程卫生规则

- **需求**：GOV-01、CFG-01、DOCKER-02
- **前置**：P00 Gate 通过。
- **结果**：仓库明确忽略虚拟环境、依赖、构建产物、`.env`、数据库、上传和向量数据，同时保留 `.env.example` 的跟踪能力。
- **允许文件**：根 `.gitignore`、`.gitattributes`、`.editorconfig`。
- **实现**：Windows/Linux 行尾规则；`*.sh` 强制 LF；Python/Node/IDE/coverage/data 规则；不得忽略 `demo_data/`、迁移或 lockfile。
- **验证**：`git check-ignore -v .env data/app.db frontend/node_modules backend/__pycache__/x.py`；`git check-ignore -v .env.example` 应返回非零；`git diff --check`。
- **负向**：创建假文件验证后要安全删除，仅限刚创建的测试文件。
- **完成门**：规则准确，无宽泛忽略源码目录。

## P01-T02：创建 FastAPI 最小后端与 health 测试

- **需求**：ARC-01、UI-01 的 API 基础
- **前置**：P01-T01。
- **结果**：`GET /api/v1/health` 返回 200、`status=ok` 与应用版本；`request_id` 通过 `X-Request-ID` 响应头返回。
- **允许文件**：`backend/pyproject.toml`、`backend/app/main.py`、`backend/app/api/**`、必要 `__init__.py`、`backend/tests/test_health.py`。
- **非目标**：数据库、业务路由、Provider、CORS 细化。
- **实现**：应用工厂或清晰入口；路由前缀只定义一次；依赖写入 `pyproject.toml`，开发依赖含 pytest/httpx/ruff/mypy；后端精确版本使用可复现 lock 文件。
- **验证**：创建 `.venv`；安装 `-e ".\backend[dev]"`；运行 `python -m pytest backend/tests/test_health.py -q` 和 `python -m ruff check backend`。
- **负向**：未知路径返回 404，不得被全局 catch 转成 200。
- **完成门**：测试与 lint 退出 0，`main.py` 无业务逻辑。

## P01-T03：创建 Vite/React/TypeScript 前端骨架

- **需求**：UI-01、TEST-03
- **前置**：P01-T01。
- **结果**：前端依赖可锁定安装，lint、typecheck、最小测试和 production build 均有脚本。
- **允许文件**：`frontend/**`。
- **非目标**：业务页面、API 请求、最终视觉。
- **实现**：使用 npm、React、TypeScript、Vite、Vitest/RTL、ESLint；必须提交 `package-lock.json`；删除模板广告资源。
- **验证**：`npm --prefix frontend ci`、`npm --prefix frontend run lint`、`npm --prefix frontend run typecheck`、`npm --prefix frontend run test:unit`、`npm --prefix frontend run build`。
- **负向**：测试一个不存在的标题，确保测试工具真正会失败，随后恢复正确断言。
- **完成门**：四条质量命令退出 0，构建产物被忽略。

## P01-T04：实现前端应用壳与占位路由

- **需求**：UI-01、UI-03
- **前置**：P01-T03。
- **结果**：桌面端 Sidebar 可导航到 Dashboard、知识库、Chat、Settings 和 404；页面明确显示“功能尚未实现”，不伪造数据。
- **允许文件**：`frontend/src/app/**`、`layouts/**`、`pages/**`、`styles/**` 和相应测试。
- **非目标**：真实 API、CRUD、图表、复杂响应式。
- **实现**：Ant Design ConfigProvider/Layout/Menu；克制的 SaaS 主题；路由懒加载可选但不可破坏测试。
- **验证**：RTL 测试所有导航；前端 lint/typecheck/test/build。
- **负向**：访问未知路由显示 404 页面，不白屏。
- **完成门**：无 Emoji、无夸张渐变/动画、无虚假 Dashboard 数值。

## P01-T05：建立安全启停脚本并执行 P01 Smoke Gate

- **需求**：GOV-02、TEST-03
- **前置**：P01-T02、P01-T04。
- **结果**：`scripts/bootstrap.ps1`、`start-dev.ps1`、`stop-dev.ps1` 可重复使用；真实进程中 health/前端可访问，production build 成功。
- **允许文件**：上述三个脚本、仅为修复 Gate 失败所需的 P01 文件；验收证据写入 `EXECUTION_STATE.md`。
- **实现**：bootstrap 使用根 `.venv` 和 npm lock；start 将本项目 PID 写入被忽略的 `.runtime/`，后台窗口隐藏；stop 只终止记录且命令行匹配本项目的 PID，不按端口或进程名宽杀。
- **验证**：运行 bootstrap/start；请求 `http://127.0.0.1:8000/api/v1/health` 和 `http://127.0.0.1:5173/`；运行全部 P01 后端测试和前端质量命令；stop；`git diff --check`。
- **负向**：停止后端后请求必须失败；重复 stop 幂等；不得终止其他 Python/Node 进程。
- **完成门**：记录命令、退出码和 health 响应；进程正常关闭；无遗留端口占用。
