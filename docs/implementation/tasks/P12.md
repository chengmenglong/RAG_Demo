# P12：Chat、Citation 与 Settings 前端

阶段目标：完成客户可见的 UI 核心闭环，确保引用点击与后端 source 完全一致。

## P12-T01：实现会话列表、新建、切换与删除

- **需求**：CHAT-01、UI-01、UI-02
- **前置**：P11 Gate。
- **结果**：Chat 页面绑定一个知识库，显示历史会话，支持新建、切换、删除和刷新恢复。
- **允许文件**：chat page/layout/services/hooks/types/tests。
- **实现**：无 KB 引导选择/创建；URL 持有 session ID；删除确认；空历史；最近会话排序。
- **验证**：MSW 流程和真实后端流程；刷新深链；删除当前会话后选择安全 fallback。
- **负向**：未知/已删 session 显示可恢复错误，不白屏。
- **完成门**：不同 KB 会话不混合。

## P12-T02：实现消息区、输入、Loading/Error、Markdown 与复制

- **需求**：CHAT-02、CHAT-03、UI-02
- **前置**：P12-T01。
- **结果**：用户可提问，看到用户/assistant 消息、等待状态、失败重试提示、Markdown/代码块和复制答案。
- **允许文件**：chat message/composer components/hooks/tests。
- **实现**：发送时防重复；非流式 skeleton；react-markdown + remark-gfm，不启用 raw HTML；长代码可滚动；复制反馈。
- **验证**：success/no-evidence/timeout/network error/empty input/long answer/Markdown code。
- **负向**：包含 `<script>`/事件属性的回答不能执行；错误不得生成 completed 的伪回答，应展示后端持久化的 failed assistant 状态。
- **完成门**：失败 user message 状态与后端历史一致。

## P12-T03：实现可点击 Citation 与来源 Drawer

- **需求**：CIT-01、CIT-02、CIT-03
- **前置**：P12-T02。
- **结果**：回答中的合法 `[S1]` 与来源卡可点击，Drawer 显示文档名、页码/章节、分数和原文；历史源已删时显示提示。
- **允许文件**：citation renderer/Drawer/types/tests。
- **实现**：只链接 response sources 中存在的 label；未知标签按普通文本；非 PDF 显示章节或“无页码”；excerpt 不加工。
- **验证**：点击 inline label/来源卡；数据与 API source 深相等；未知标签；deleted source；键盘可达。
- **负向**：不得依据 LLM 文本去请求任意 document/chunk ID；不渲染 raw HTML。
- **完成门**：Citation 显示值完全来自结构化对象。

## P12-T04：实现 Settings 表单和变更语义提示

- **需求**：SET-01、SET-02、SET-03
- **前置**：P10-T01、P06-T01。
- **结果**：可配置 provider/base URL/model/temperature/top-k/threshold/chunk size/overlap；Key 仅显示已配置/未配置。
- **允许文件**：Settings page/components/hooks/tests。
- **实现**：LLM 与 Embedding 分组；边界校验；保存/重置反馈；说明 Key 需环境变量；Chunk 参数只影响新上传或 reprocess；Embedding 默认值只影响未绑定 KB，已绑定 KB 即使 reprocess 也继续使用原 profile，改模型必须新建 KB。
- **验证**：加载、修改、刷新持久、422、network error、configured badge。
- **负向**：DOM、表单 state、network response 和 bundle 中不得出现实际 API Key。
- **完成门**：不可编辑/读取 Key 值，Base URL 不是 Key 的替代字段。

## P12-T05：实现 Demo/Provider 状态与可用性反馈

- **需求**：DEMO-01、PROV-02、UI-02
- **前置**：P12-T04。
- **结果**：Demo 模式清楚标识；真实 Provider 缺配置时给出可操作提示；不把 Mock 说成真实模型。
- **允许文件**：前端 badge/notice/tests；只使用 `GET /settings`、health 与当前 Chat 错误，不新增契约外 Provider Status API。
- **实现**：显示 provider/model、Key configured 和 health/demo 状态；不保存“最近失败历史”，本 MVP 不新增测试连接端点。
- **验证**：Demo、OpenAI 缺 Key、Ollama 不可达、配置完整状态。
- **负向**：连接测试失败不得自动切 Demo 后显示成功。
- **完成门**：用户能分辨离线 Demo 与真实 Provider。

## P12-T06：执行完整 UI 核心闭环 Gate

- **需求**：GOV-02、CIT-02、CHAT-01、SET-01、TEST-04、UI-03
- **前置**：P12-T01 至 T05。
- **结果**：真实浏览器从建库到点击引用全流程成功，空/错误状态同样可见。
- **实现**：为 Chat/Citation/Settings 增加带 `@p12` 标签的 Playwright 用例。
- **验证**：frontend lint/typecheck/test/build；`npm --prefix frontend run test:e2e -- --grep "@p12"`；真实前后端建库→上传唯一事实→ready→新会话→提问→点击 source→核对 excerpt；刷新历史；修改 top-k；两 viewport；console 0 error。
- **负向**：无关问题拒答、Provider timeout、未知 citation label、已删源历史。
- **完成门**：保存截图/Playwright trace 或逐步操作证据；失败不得进入 P13。
