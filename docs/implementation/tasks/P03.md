# P03：知识库与 Dashboard 后端

阶段目标：在不依赖文档处理的前提下，完成知识库 CRUD 和真实 SQL Dashboard 统计。

## P03-T01：实现 KnowledgeBase 模型、迁移与 Repository

- **需求**：KB-01、KB-02、DB-02
- **前置**：P02 Gate。
- **结果**：知识库可持久化 UUID、名称、描述、Embedding Profile 空字段和 UTC 时间。
- **允许文件**：`models/knowledge_base.py`、`repositories/knowledge_base.py`、模型导出、一个 Alembic revision、测试。
- **实现**：名称非空；同名允许；列表按 `updated_at DESC, id DESC`；repository 只做持久化，不抛 HTTPException。
- **验证**：迁移 upgrade；create/get/list/update/delete repository 测试；时间更新测试。
- **负向**：随机 UUID 查询返回 `None`；空白名称不得落库。
- **完成门**：索引和字段与数据契约一致，无 SQLite 专属业务 SQL。

## P03-T02：实现知识库 Schema 与 Service

- **需求**：KB-01、SEC-01
- **前置**：P03-T01。
- **结果**：创建/更新输入被统一清洗校验；不存在资源映射为稳定 `RESOURCE_NOT_FOUND`，安全 details 可说明资源类型为 knowledge_base。
- **允许文件**：`schemas/knowledge_base.py`、`services/knowledge_base_service.py`、测试。
- **实现**：strip 名称和描述；长度边界；PATCH 区分未提供与显式 null；业务事务在 service。
- **验证**：合法/边界/空白/超长/404 service 测试。
- **负向**：禁止通过 PATCH 修改 id、created_at、embedding profile。
- **完成门**：service 不依赖 FastAPI Request，schema 不泄露 ORM 内部字段。

## P03-T03：实现知识库 CRUD API

- **需求**：KB-01、UI-01
- **前置**：P03-T02。
- **结果**：`GET/POST /knowledge-bases` 与 `GET/PATCH/DELETE /knowledge-bases/{id}` 按契约工作。
- **允许文件**：`api/v1/knowledge_bases.py`、router、API 测试。
- **实现**：列表分页；POST 201；DELETE 204；UUID/422、404 使用统一错误；路由只调用 service。
- **验证**：完整 CRUD API 测试、分页/排序、刷新持久性。
- **负向**：非法 UUID、空名称、未知 ID、越界分页均有断言。
- **完成门**：OpenAPI 路径和 schema 正确，无路由直接写 SQL。

## P03-T04：实现 Dashboard 查询与 API

- **需求**：DASH-01、KB-02
- **前置**：P03-T01、P03-T03。
- **结果**：`GET /dashboard` 返回知识库数、文档数、有效 Chunk 数、最近知识库、最近上传和快速问答目标所需数据。
- **允许文件**：`repositories/dashboard.py` 或聚合查询、`services/dashboard_service.py`、schema、route、测试。
- **实现**：最近知识库按 updated_at；最近文档按 created_at；默认各 5 条；`document_count` 统计所有文档，`ready_document_count` 只统计 ready，`chunk_count` 只统计所属文档 ready 且 profile 与 KB 一致的 Chunk；当前尚无 Document/Chunk 表时返回 0/空，相关模型创建任务必须补真实聚合测试。
- **验证**：空状态与多个知识库排序；不得硬编码示例数据。
- **负向**：删除知识库后计数立即更新。
- **完成门**：所有值来自数据库查询，响应与契约兼容后续扩展。

## P03-T05：执行知识库与 Dashboard Gate

- **需求**：KB-01、KB-02、DASH-01、TEST-01
- **前置**：P03-T01 至 T04。
- **结果**：从空库迁移后，API 可创建、编辑、列出、查看、删除并返回真实 Dashboard。
- **验证**：P01–P03 全部 pytest/Ruff；真实 Uvicorn API smoke；重启后知识库仍存在；`git diff --check`。
- **负向**：非法参数、404、数据库事务失败路径；确认错误响应无栈。
- **完成门**：成功与负向证据均记录；后续 Document 外键可安全引用 KB。
